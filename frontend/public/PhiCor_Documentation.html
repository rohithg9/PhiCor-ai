1. Overview

PhiCor.ai is a comprehensive digital twin platform that mathematically models the human body across multiple biological scales. It provides clinicians, researchers, and medical experts with an interactive tool to explore physiological parameters, disease modifications, drug effects, and differential diagnoses.

Key Features

🏥 1,977 Disease Models

AI-enhanced parameter modifications for comprehensive disease representation.

💊 336+ Drug Profiles

Complete physiological effects modeling for common medications.

🫀 18 Organ Systems

Heart, Brain, Lungs, Liver, Kidneys, and 13 more organ systems.

📊 10 Biological Scales

Geometry, Pressures, ECG, Cellular, Lab Tests, and more.

Technology Stack

  • Frontend: React.js with Tailwind CSS & shadcn/ui
  • Backend: FastAPI (Python)
  • Database: MongoDB
  • AI: OpenAI GPT-4o via Emergent LLM Key

6. Differential Diagnosis

The AI-powered differential diagnosis panel analyzes abnormal parameters and generates a ranked list of possible diagnoses with probability scores and key distinguishing features.

How It Works

  1. Select an organ system with abnormal parameters
  2. AI analyzes the parameter pattern
  3. Generates ranked differential diagnoses
  4. Each diagnosis shows: probability score, supporting findings, differentiating features

8. Knowledge Bank

The Knowledge Bank allows administrators to upload medical documents, URLs, and text for AI analysis. The system automatically extracts parameter updates, guideline changes, and clinical modifications, creating suggestions for admin approval.

📚
Knowledge Bank
3 Sources • 3 Pending Suggestions

Figure 8.1: Knowledge Bank with AI-analyzed sources and pending suggestions

Features

  • Upload Sources: URLs, PDFs, Documents, or direct text input
  • AI Analysis: GPT-4o extracts medical updates automatically
  • Suggestions: Review proposed changes with evidence levels and confidence scores
  • Approval Workflow: Approve or reject each suggestion
  • Auto-Search: Scheduled AI search for new guidelines (configurable 7-90 days)

Workflow

  1. Click "Add Knowledge"
  2. Select type: URL / Document / Text
  3. Enter title and content
  4. Optionally link to a disease
  5. Click "Upload & Analyze"
  6. AI extracts suggestions automatically
  7. Review and approve/reject each suggestion

10. API Reference

PhiCor.ai provides a comprehensive REST API for integration with external systems. All protected endpoints require JWT authentication.

Authentication

POST /api/experts/login
Body: {"email": "...", "password": "..."}
Returns: {"access_token": "...", "expert": {...}}

All protected endpoints require: Authorization: Bearer {token}

Core Endpoints

Endpoint Method Description
/api/experts/login POST Authenticate and get JWT token
/api/experts/diseases-to-review GET Get all diseases with modifications
/api/disease/{id}/parameters GET Get parameters for specific disease
/api/change-requests POST Submit parameter change request
/api/admin/knowledge/upload POST Upload knowledge source
/api/admin/knowledge/suggestions GET Get pending AI suggestions
/api/admin/experts GET/POST List/Create experts
/api/admin/settings GET/PUT System settings
/api/enhancement/status GET Check data enhancement progress
